# Heelo Onboarding

Connect Heelo to Codex without copying an API key or editing MCP settings by hand.

**Preview.** This quickstart is under testing. Live browser sign-in may not be available yet.

## Quickstart

Copy the URL of this GitHub page and paste the following into a fresh Codex session, replacing `<REPO_URL>` with the URL you copied.

> Set up Heelo in Codex using <REPO_URL>. Tell me when I need to sign in or approve access in my browser, then verify that I can use a Heelo tool.

Codex should follow [SKILL.md](./SKILL.md) and tell you what worked or what blocked setup.
